# Current source provenance snapshots

These files were copied from local experiment projects on2026-10-27.
They are current source/launcher snapshots, not proof that every historical
run used exactly these bytes. When available, a run's original training_source.py,
source_hash.json, arguments.json and actual_data_audit.json are in the raw archive.
DeCon snapshots are not a standalone installation: its original dependencies,
other models/utils and dataset augmentation modules are still required.
Paths in launchers are machine-specific; they are preserved for provenance.
